公式入门 —— 从"算总价"开始认识公式

▼

📖 知识讲解

在 Excel 里，"计算"不是用计算器按出来的，而是写一条公式，让 Excel 帮我们算。公式写一次，以后数据变了，结果会自动跟着变——这就是 Excel 最迷人的地方。

🔹 第一条规矩：公式必须以 = 开头

所有公式、所有函数，前面都要加一个英文等号 =。不加等号，Excel 会把它当成普通文字。比如想算 3+5，要写 =3+5，而不是 3+5。

🔹 五种算术运算符
运算符含义例子结果
+加=2+35
-减=10-46
*乘（星号）=6*742
/除（斜杠）=20/45
^乘方（幂）=2^38
%百分比=50%0.5
🔹 运算优先级（先算谁后算谁）

和数学一样，Excel 也讲"先乘除后加减"。规则是：

括号 ( ) > 乘方 ^ > 乘除 * / > 加减 + -
  • =2+3*4 先算 3×4=12，再加 2，结果是 14
  • =(2+3)*4 先算括号里 2+3=5，再 ×4，结果是 20
💡 拿不准先算谁的时候，一律加括号！括号能让你的意图清清楚楚，也最不容易出错。
🔹 关键技巧：公式里用"单元格地址"，别用数字

这是新手最容易踩的坑。假设 B2 是单价、C2 是数量，正确写法是 =B2*C2，而不是 =12.9*2。

  • 用地址：以后你把 B2 的单价改成 15，金额会自动重算。
  • 用死数字：改了单价，公式还是 25.8，永远不会变——这就失去了 Excel 的意义。
🔹 编辑栏与 F2：查看和编辑公式

单元格里默认只显示计算结果，真正的公式藏在编辑栏（顶部 fx 那一行）。

  • 单击单元格 → 编辑栏里看到完整公式。
  • 双击单元格，或按 F2，可以直接在单元格里修改公式。
🔹 一键看穿所有公式：Ctrl+~

按 Ctrl+~（波浪号，数字 1 左边那个键），整张表会从"显示结果"切换成"显示公式"，方便你检查哪里写错了。再按一次恢复原样。也可以用 公式 选项卡 → 显示公式。

🔹 公式的复制与自动填充

写好第一个公式后，不用一个个重写。选中含公式的单元格，拖动右下角的填充柄（小绿十字）往下拉，Excel 会把公式"智能"地复制到每一行，地址自动顺延（这叫相对引用，下节课细讲）。

🔹 自动求和快捷键：Alt+=

想对一列数求和？选中要放结果的空白单元格，按 Alt+=，Excel 会自动帮你写 =SUM(...) 并猜出要求和的区域，回车即可。

🔹 三个最常见的出错值

⚠️ 公式算不出来，单元格里出现这些奇怪的字，先别慌：

  • #VALUE! —— 把文字和数字硬算在一起，比如 ="苹果"+5
  • #DIV/0! —— 除以了 0，比如 =10/0 或分母单元格是空的
  • #NAME? —— Excel 看不懂你写的名字，通常是函数名拼错（=SUMMA(...)）或忘写引号

🔧 操作步骤：用公式算出超市小票的金额

我们用一份 20 行的"超市购物小票"来练手，金额列先留空，由你用公式填出来。

下载下面的 CSV，把数据整理成表格：A列序号、B列商品名称、C列单价、D列数量、E列金额
单击 E2，输入 =C2*D2（单价 × 数量），按 Enter，应看到第 1 行金额
选中 E2，把鼠标移到单元格右下角，当出现小绿十字（填充柄）时，按住左键往下拖到 E21

选中 E22（金额下方空单元格），按 Alt+=，Excel 自动生成 =SUM(E2:E21)，回车得到总价
把 C2 的单价随便改一个数，看 E 列和总价是不是自动跟着变——这就对了！

💡 技巧提示

  • 公式里出现 #DIV/0!，多半是分母单元格还是空的——先把分母数据填上
  • 双击填充柄可以一键填充到底（只要左边/上边有连续数据），比拖拽更快
  • 想看某个公式引用了哪些单元格？单击它，Excel 会用彩色框把引用的区域圈出来
  • 按 F2 进入编辑后，用方向键在公式里移动光标，比用鼠标方便
  • 写错公式想重来？选中单元格按 Delete 清空，再重新输入即可

📐 操作规范（养成好习惯）

  • 公式一律引用单元格，不要直接写死数字，方便后续修改和复用
  • 表头在第 1 行，金额等"算出来的列"也要有表头（如"金额""总价"）
  • 数据连续存放，行与行之间不要留空行，否则自动填充和求和会断掉
  • 金额列保持为数值格式，不要手打成"￥25.8"这样的文字
  • 重要的计算表另存备份（如"小票计算_v2.xlsx"），公式改坏了还能找回

⚠️ 常见错误

  • ❌ 忘记写开头的 = → 写 C2*D2 变成普通文字，不会计算
  • ❌ 把乘号写成 × 或字母 x → Excel 只认 *
  • ❌ 公式里直接写死数字 =12.9*2 → 改了单价结果不变，白忙一场
  • ❌ 填充时只拖了公式却没覆盖全部行 → 部分行金额空白，求和少算
  • ❌ 把 / 写成中文顿号或反斜杠 → 报 #NAME? 错误

单元格引用 —— 相对引用、绝对引用与 $ 符号

▼

📖 知识讲解

"引用"就是公式里写的那个单元格地址（如 A1）。Excel 在复制公式时，会根据引用方式自动调整或固定地址，这就是相对、绝对、混合三种引用的区别。

🔹 相对引用 A1（默认）

不加 $ 的就是相对引用。公式往下复制时，行号会跟着变；往右复制时，列字母会跟着变。

例子：在 E2 写 =C2*D2，向下填充
E2: =C2 * D2
E3: =C3 * D3  （行号自动 +1）
↳ 适合"每一行都用自己的数据算"的场景
🔹 绝对引用 $A$1（锁死不动）

在列字母和行号前都加 $，公式复制到哪，这个地址永远不变。常见于"折扣率""汇率"这种全表共用的固定值。

例子：折扣率锁在 $B$1，折后价 = 原价 × 数量 × 折扣率
F2: =C2 * D2 * $B$1
F3: =C3 * D3 * $B$1  （只有 C、D 变，$B$1 不动）
↳ 想改全场折扣？只改 B1 一个格子，整列折后价全变
🔹 混合引用 $A1 与 A$1

只锁一半：$A1 锁列不锁行（往右复制列不变，往下复制行变）；A$1 锁行不锁列（往下复制行不变，往右复制列变）。做乘法表时特别好用。

🔹 F4：一键循环切换四种引用

编辑公式时，把光标放在地址上，连按 F4 会在四种状态间循环：

A1→ $A$1→ A$1→ $A1→ A1
🔹 三种引用对比
类型写法向下复制典型用途
相对引用A1行号变每行算自己的数据
绝对引用$A$1不变折扣率、税率、单价表
混合引用$A1 / A$1锁一半乘法表、交叉表
🔹 跨工作表引用：Sheet1!A1

公式要用另一个工作表的数据，写法是 表名!单元格。比如 Sheet2 的 B2 想引用 Sheet1 的 A1：

=Sheet1!A1 * 2

表名有空格或中文时要加单引号：='销售数据'!A1。

🔹 跨工作簿引用：[文件名.xlsx]Sheet1!A1

引用另一个 Excel 文件里的单元格，写法是 [工作簿名]表名!单元格：

=[价格表.xlsx]Sheet1!B2
⚠️ 跨工作簿引用要求两个文件都打开，且源文件移动/改名后引用会断。正式交付建议把数据整合进同一个文件。
🔹 引用失效 #REF!

当你删除了公式所引用的行/列/工作表，Excel 找不到原来的位置，就会显示 #REF!。它一旦出现，原始引用就丢了，比 #N/A 更难修，所以删行前先检查有没有公式依赖它。

🔧 操作步骤：用绝对引用算全场折扣

💡 技巧提示

  • 不确定该不该加 $？问自己：复制后这个地址要不要跟着变？ 不变的就锁
  • 编辑公式时按 F4 循环切换，比手敲 $ 快且不易错
  • 跨表引用时，直接用鼠标点目标单元格，Excel 会自动补全 Sheet名!地址
  • 想引用整列？写 B:B（绝对列引用），但求和时要避开结果所在列防循环
  • 偶尔需要"半锁定"做九九表，就靠混合引用 $A1 / A$1

📐 操作规范（养成好习惯）

  • 共用参数单独放一格（折扣率、税率、汇率），并用绝对引用锁住，方便统一调整
  • 参数单元格要有清晰标注，如旁边写"折扣率(0.9=九折)"，别让同事猜
  • 跨表/跨簿引用越少越好，正式报表尽量合并到同一工作簿
  • 删除行/列前，先检查是否有公式引用它，避免产生 #REF!
  • 工作表命名含中文或空格时，跨表引用要加单引号

⚠️ 常见错误

  • ❌ 折扣率没锁 $ → 向下填充后变成 B2、B3、B4…，只有第一行算对
  • ❌ 把折扣率写死在公式里 =B2*C2*0.9 → 想改全场折扣得改 30 个公式
  • ❌ 跨表引用忘了表名或写错 → 报 #NAME? 或 #REF!
  • ❌ 删除了被引用的行 → 公式显示 #REF!，且原始引用无法自动恢复
  • ❌ 跨工作簿引用时源文件已关闭 → 显示 #REF! 或旧值

求和与统计函数 —— SUM、AVERAGE、MAX、MIN、COUNT

▼

📖 知识讲解

函数就是 Excel 自带的"现成算法"。写法和公式一样以 = 开头，格式固定为 =函数名(参数1, 参数2, ...)。参数之间用英文逗号 , 隔开。

💡 参数可以是具体数字（如 =SUM(1,2,3)）、单元格（如 =SUM(A1)），或区域（如 =SUM(A1:A10)）。最常用的是"区域"。
🔹 五大统计函数一览
SUM
=SUM(A1:A10)

求和，把所有数字加起来

AVERAGE
=AVERAGE(A1:A10)

求平均值

MAX
=MAX(A1:A10)

找最大值

MIN
=MIN(A1:A10)

找最小值

COUNT
=COUNT(A1:A10)

数一数有几个数字

🔹 SUM —— 求和

最常用。除了手动写，还可以用功能区 开始 选项卡里的 Σ 自动求和 按钮，或快捷键 Alt+=。

SUM(C2:C41)   求 C2 到 C41 的总和
🔹 AVERAGE —— 平均值
AVERAGE(C2:C41)   相当于 =SUM(C2:C41)/COUNT(C2:C41)
🔹 MAX / MIN —— 最大 / 最小

用来找"最高分""最低销量"等。比如 =MAX(D2:D41) 找出数学最高分。

🔹 COUNT 家族：三个"数数"函数别搞混
函数数什么例子
COUNT只数数字单元格=COUNT(A1:A10) → 数字个数
COUNTA数非空单元格（含文字）=COUNTA(A1:A10) → 已填个数
COUNTBLANK数空白单元格=COUNTBLANK(A1:A10) → 空单元格数
⚠️ COUNT 只认数字！如果一列是"文本型数字"（带绿三角的那种），COUNT 会把它漏掉。要数全部内容用 COUNTA。
🔹 连续区域 vs 不连续区域

一次求多个不相邻区域，用逗号隔开：

SUM(A1:A5, C1:C5)   把 A 列和 C 列两段分别求和后再相加
🔹 状态栏：不用写公式也能看统计

用鼠标选中一片数据，看 Excel 窗口最右下角的状态栏，会自动显示：平均值、计数、求和。右键状态栏还能切换显示哪些指标——临时看一眼数据特别快。

🔹 函数嵌套的雏形

函数里可以套函数。例如"求平均"其实就是"总和÷个数"：

SUM(A1:A5) / COUNT(A1:A5)   和 AVERAGE 等价

这就是"嵌套"思想的起点，后面的 IF、SUMIF 都是在这个基础上叠加的。

  • 状态栏是"免公式快速预览"神器，临时判断数据量级超好用
  • COUNT 和 COUNTA 结果不一致？多半是混进了文本，检查一下数据格式

📐 操作规范（养成好习惯）

  • 表头清晰：总分、平均分等计算列都要有表头，别让看表的人猜
  • 统计区域要选全且不含表头（表头是文字，会被 COUNT 漏掉但 SUM 会当 0）
  • 人数/科数这类"计数"优先用 COUNTA，避免文本型数字被 COUNT 漏计
  • 函数参数用英文逗号；如果系统是中文标点，记得切换中英文
  • 关键统计结果（最高/最低/平均）可加粗或变色突出，但全表颜色不超过 4 种

⚠️ 常见错误

  • ❌ 求和区域把表头也圈进去了 → 表头是文字，SUM 当 0 处理虽不影响，但 COUNT 会少算
  • ❌ 把 COUNT 当"数人数"用 → 文本姓名它一个都不数，应用 COUNTA
  • ❌ 函数名拼错或中文括号 → 报 #NAME?
  • ❌ 参数用英文分号 ; 而非逗号 , → 某些地区设置下才用分号，默认用逗号
  • ❌ 平均分写成 =SUM/4 而非 =AVERAGE，且没锁定列 → 填充后列错乱

逻辑函数 —— IF 让 Excel 会"判断"

▼

📖 知识讲解

前面的函数只会"算数"，而 IF 函数让 Excel 学会"判断对错再做决定"——这正是从"计算器"升级到"小助手"的关键一步。

🔹 先认识：比较运算符

IF 的"条件"靠比较运算符写出，结果是 TRUE（真）或 FALSE（假）：

运算符含义例子结果
=等于=5=5TRUE
>大于=8>3TRUE
<小于=2<1FALSE
>=大于等于=6>=6TRUE
<=小于等于=4<=3FALSE
<>不等于=5<>3TRUE
🔹 IF 的三段式
IF(条件, 成立时返回, 不成立时返回)

例如"金额≥99 包邮，否则不包邮"：

IF(C2>=99, "包邮", "不包邮")
💡 返回的文字必须用英文双引号包起来；返回数字则不用引号。这是 IF 最常写错的地方。
🔹 TRUE / FALSE 是什么

比较表达式本身就会返回一个逻辑值。=5>3 显示 TRUE，=5>8 显示 FALSE。IF 正是拿这个真假来决定走哪条路。

🔹 AND / OR / NOT：把多个条件揉在一起
AND
=AND(条件1,条件2)

全部为真才真（"而且"）

OR
=OR(条件1,条件2)

有一个真就真（"或者"）

NOT
=NOT(条件)

真假颠倒

例子：金额≥99 且 地区不是"偏远"才包邮：

IF(AND(C2>=99, D2<>"偏远"), "包邮", "不包邮")
🔹 IF 嵌套：做多级判断（成绩等级）

等级评定"优/良/中/及格/不及格"要一层套一层，从最高档往下写：

成绩 → 等级
IF(A1>=90,"优",
  IF(A1>=80,"良",
    IF(A1>=70,"中",
      IF(A1>=60,"及格","不及格"))))
↳ 每多一级就多包一层 IF，括号数量要配对
🔹 IFERROR：给公式加"安全气囊"

当公式可能报错（比如除以 0、查不到数据）时，用 IFERROR 指定"出错时显示什么"，避免满屏 #DIV/0!：

IFERROR(公式, "出错时显示的内容")

例：=IFERROR(B2/C2,"无数据")，C2 为空时显示"无数据"而不是错误值。

🔹 电商里的 IF 业务判断
  • 是否包邮：订单金额≥包邮门槛 → "包邮"，否则"不包邮"
  • 是否达标：销售额≥目标 → "达标"，否则"未达标"
  • 是否超预算：实际支出>预算 → "超预算"，否则"正常"

  • ❌ AND/OR 参数写成一个整体 =AND(C2>=99,D2<>"偏远") 写成 =AND(C2>=99 AND D2<>"偏远") → 语法错

条件统计函数 —— SUMIF、COUNTIF、SUMIFS、COUNTIFS

▼

📖 知识讲解

前面的 SUM/COUNT 是"全算"，而这节课的带 IF 的兄弟们是"只算满足条件的那部分"——电商日报、月报里 80% 的统计都靠它们。

🔹 SUMIF —— 按条件求和
SUMIF(条件区域, 条件, 求和区域)

在"条件区域"里找符合条件的行，把对应"求和区域"的值加起来。例：求"店铺A"的总销售额：

SUMIF(C:C, "店铺A", H:H)
💡 当"条件区域"和"求和区域"是同一列时，求和区域可省略，写成 =SUMIF(C:C,"店铺A")。
🔹 COUNTIF —— 按条件计数
COUNTIF(区域, 条件)

统计区域里满足某条件的单元格个数。例：统计"已发货"状态有多少单：

COUNTIF(I:I, "已发货")
🔹 条件怎么写（重点！）
想要的条件写法说明
等于某值"手机"直接写文本
大于 1000">1000"大于号放引号内
不等于"已取消""<>已取消"不等于用 <>
包含"手机""*手机*"★ 任意多个字符
单字符匹配"手?"? 代表单个字符
大于某单元格">="&B1符号+&连接单元格
⚠️ 带比较符号（> < >=）或连接单元格（&B1）时，必须用 & 把符号和引用拼起来，且符号本身在引号里。
🔹 通配符 * 与 ?
  • *（星号）= 任意多个字符："*手机*" 能命中"华为手机""手机壳"
  • ?（问号）= 任意一个字符："手机?" 命中"手机1"但不命中"手机壳"
🔹 SUMIFS / COUNTIFS —— 多条件（求和区域在前！）

多个条件同时满足时才统计。注意参数顺序和 SUMIF 相反：求和/计数区域排在最前：

SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2)
SUMIFS(H:H, C:C, "店铺A", I:I, "已发货")   店铺A且已发货的销售额

COUNTIFS 同理：=COUNTIFS(C:C,"店铺A",I:I,"已发货")

🔹 AVERAGEIF / AVERAGEIFS

按条件求平均，结构和 SUMIF 一致：=AVERAGEIF(C:C,"店铺A",H:H)。

🔹 IF 与 SUMIF 的分工
✅ 一句话分清：IF 是"对每一行逐行判断返回不同结果"；SUMIF/COUNTIF 是"跨很多行汇总出一个总数/总次数"。要逐行打标签用 IF，要算合计用 SUMIF。

查找与引用 —— VLOOKUP 与它的伙伴们

▼

📖 知识讲解

日常工作中，"按编码查价格""按姓名查部门"是高频需求。VLOOKUP 就是干这个的：给一个"钥匙"，去表里竖着查找并返回对应信息。

🔹 VLOOKUP 四参数
VLOOKUP(查找值, 查找区域, 返回第几列, 0)
  • 查找值：你要拿去匹配的"钥匙"，如商品编码
  • 查找区域：去哪张表里找，必须包含"钥匙列"和"要返回的列"
  • 返回第几列：从查找区域最左列算起，第几列是你要的结果（1 就是钥匙本身那列）
  • 第四参数 0：固定写 0，表示精确匹配（找不到就报错）。写 1 是模糊匹配，新手别用
例：按商品编码查单价
VLOOKUP(A2, $E$2:$G$31, 3, 0)
↳ A2=要查的编码；E:G 是价格表（E编码/F名称/G单价），单价在第3列；0=精确匹配
🔹 铁律 1：查找值必须在查找区域的第一列

VLOOKUP 只能往右找。所以你的查找区域，最左边必须是"钥匙列"（如商品编码）。如果钥匙在右边，要么调整列顺序，要么改用下面的 INDEX+MATCH。

🔹 铁律 2：查找区域要用 $ 锁定

因为要往下填充，查找区域必须绝对引用 $E$2:$G$31，否则下拉后区域跑偏，查出一堆错。

🔹 铁律 3：第四参数用 0

绝大多数业务查询都要精确匹配，第四参数写 0（也可写 FALSE）。写 1/TRUE 会做"近似匹配"，极易查错。

🔹 #N/A 的五种常见原因
  • ① 查找值在表里根本不存在（编码输错、多了空格）
  • ② 查找值有多余空格（"A001 "≠"A001"），用 TRIM 处理
  • ③ 查找区域没锁 $，下拉后区域错位
  • ④ 返回的列号超出了查找区域范围
  • ⑤ 数据类型不一致：一边是文本"001"、一边是数字 1，永远对不上
🔹 用 IFERROR 包一层，优雅处理查不到
IFERROR(VLOOKUP(A2,$E$2:$G$31,3,0), "未找到")

查不到时显示"未找到"而不是刺眼的 #N/A。

🔹 更灵活的 INDEX + MATCH

VLOOKUP 只能向右找，INDEX+MATCH 可以左右随便找：

INDEX(返回列, MATCH(查找值, 钥匙列, 0))

MATCH 负责"钥匙在第几行"，INDEX 负责"取那行某列的值"，组合起来不受方向限制。

🔹 新版 XLOOKUP（Microsoft 365）

Excel 365 / 2021 提供了更简单的 XLOOKUP，不用数第几列、不用锁区域、能向左查：

XLOOKUP(查找值, 钥匙列, 返回列)

如果学校电脑还是旧版 Excel，先掌握 VLOOKUP，XLOOKUP 作为了解即可。

💡 技巧提示

  • 返回列号数错是最常见的错，写公式前先在查找区域里从左往右数一遍
  • 查不到先别慌：用 =TRIM(查找值) 清掉空格，或检查两边数据类型是否一致
  • 想避免数错列，配合 表（Ctrl+T） 可用列名，但基础阶段先练手工数
  • IFERROR 包 VLOOKUP 是标准姿势，正式报表几乎必加
  • 365 用户直接用 XLOOKUP，省去"锁区域+数第几列"两苦恼

📐 操作规范（养成好习惯）

  • 价格表、参数表这类基准数据单独放一个 Sheet，命名为"价格表""参数表"，别和明细混在一起
  • VLOOKUP 的查找区域务必加 $ 绝对引用，否则填充后全盘错
  • 编码、ID 等"钥匙"列统一格式（都用文本或都用数字），防止对不上
  • 第四参数固定写 0（精确匹配），除非你明确要做区间匹配
  • 交付前抽查 3~5 条查找结果，确认带出的信息正确

⚠️ 常见错误

  • ❌ 查找值不在查找区域第一列 → 永远查不到，应调整列序或换 INDEX+MATCH
  • ❌ 查找区域没加 $ → 下拉后区域漂移，结果乱套
  • ❌ 第四参数写成 1（模糊匹配）→ 查出不相关的值还以为对了
  • ❌ 返回列号超出范围（如区域只有 3 列却写 4）→ 报 #REF!
  • ❌ 两边数据类型不一致（文本 vs 数字）→ 满屏 #N/A

7

文本与日期函数 —— 把数据"拆开再拼起来"

▼

📖 知识讲解

真实数据常常"挤"在一个单元格里（如"浙江省杭州市西湖区"），或者格式乱七八糟。文本与日期函数就是帮你把它拆开、整理、再拼好的工具箱。

🔹 截取文本：LEFT / RIGHT / MID / LEN
LEFT
=LEFT(文本, 3)

从左边取 3 个字符

RIGHT
=RIGHT(文本, 4)

从右边取 4 个字符

MID
=MID(文本, 2, 3)

从第 2 位起取 3 个

LEN
=LEN(文本)

数一数共几个字符

例：手机号 13812345678，取前 3 位运营商号段：=LEFT(A2,3) → 138。

🔹 找位置：FIND / SEARCH

想知道"省""市"在哪个位置，用 FIND（区分大小写）/ SEARCH（不区分）：

FIND("省", A2)   返回"省"字在文本中的位置

配合 MID 就能"按关键字切分"，比如从"浙江省杭州市"取出"浙江"。

🔹 拼接：& 连接符 / CONCAT / TEXTJOIN
  • & 连接符：=A2&"-"&B2 把两格用短横拼起来
  • CONCAT：=CONCAT(A2,B2) 直接拼接多个文本
  • TEXTJOIN：=TEXTJOIN("-",,A2:C2) 用"-"把 A~C 拼起来，还能跳过空单元格
🔹 格式化显示：TEXT

把数字/日期按指定"格式代码"显示成文本：

TEXT(A1, "0000")   数字补零成 4 位，如 12 → "0012"
TEXT(A1, "yyyy年m月")   日期 → "2025年3月"
🔹 清洗：TRIM / CLEAN
  • TRIM：去掉首尾多余空格、把中间多个空格合并成一个
  • CLEAN：去掉不可打印的换行/控制字符（从系统导出的脏数据常有）
🔹 大小写：UPPER / LOWER / PROPER
  • UPPER 全大写、LOWER 全小写、PROPER 首字母大写（如英文名规范化）
🔹 日期函数家族
函数作用例子
TODAY()今天日期=TODAY()
NOW()现在日期+时间=NOW()
YEAR/MONTH/DAY取年/月/日=YEAR(A2)
WEEKDAY星期几(1~7)=WEEKDAY(A2,2)
DATEDIF两日期差=DATEDIF(开始,结束,"d")
EDATE加减月数=EDATE(A2,12)
EOMONTH某月最后一天=EOMONTH(A2,0)
💡 DATEDIF 的第三参数："y"年差、"m"月差、"d"天差。它是隐藏函数，输的时候不会自动提示，但确实能用。
🔹 文本型数字 ⇄ 数值

从系统导出的数字常是"文本"（带绿三角），不能参与计算。互转小技巧：

  • 文本转数值：--A2 或 A2*1（两个减号把文本强转成数）
  • 数值转文本：A2&""（连接空文本，变成文本）

🔧 操作步骤：从客户信息表里"拆"出有用字段

一份 40 行客户信息表，含手机号、所在省市区、注册日期等。所属省份、注册年月、入会天数、会员到期日留空，由你用文本/日期函数算。

💡 技巧提示

  • FIND 找不到会报 #VALUE!，配合 IFERROR 更稳；不区分大小写时用 SEARCH
  • 处理"省/市/区"拆分，先用 FIND 定位关键字位置，再用 MID 截取中间段
  • TEXT 之后结果是文本，不能直接当数字算，需要再 -- 转回
  • DATEDIF 算年龄、会员天数、账期差都很顺手，记住第三个参数是"y/m/d"
  • 大量脏数据先 TRIM+CLEAN 洗一遍，再去重、查找，效率翻倍

📐 操作规范（养成好习惯）

  • 拆分出的"省份""年月"等派生列放在原列右侧，并加表头，保持表格整洁
  • 日期统一用 年/月/日 真实日期格式，别手打成文字，否则无法计算天数
  • 从系统导出数据后，先清洗（TRIM/CLEAN/转数值）再分析，避免脏数据坑人
  • 手机号、身份证等保留为文本，防止前导 0 丢失或变科学计数法
  • 派生列可标为"系统计算"用浅色底，和人工录入列区分

⚠️ 常见错误

  • ❌ MID 起算位置搞错：Excel 字符从 1 开始数，不是 0
  • ❌ 把日期当文本截：LEFT(日期,4) 截到的是序列号，应先 TEXT 再截
  • ❌ FIND 找不到关键字报 #VALUE! → 用 IFERROR 兜底或先确认数据格式
  • ❌ TEXT 结果当数字用 → 求和得到 0，记得 -- 转回数值
  • ❌ 文本型数字直接相加 → 结果 0，用 -- 或 *1 转数值
